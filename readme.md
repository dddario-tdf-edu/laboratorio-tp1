¿Qué van a construir?
Un sitio de blog con:
● Página de inicio (listado de artículos en tarjetas Bootstrap)
● Página "Acerca de mí" (sección personal con foto)
● Formulario de contacto (validación HTML5 + CSS de feedback)
● Barra de navegación responsiva (Navbar de Bootstrap)
● Footer con redes sociales
● Diseño mobile-first (media queries, Bootstrap grid)
Requisitos técnicos:
● HTML5 semánticamente correcto (validar con W3C)
● Bootstrap 5 (CDN o local)
● CSS personalizado (styles.css) para branding
● Formulario con campos: nombre, email, teléfono, mensaje
● Validación HTML5 (required, type="email", etc.)
● Feedback visual en inputs (:valid, :invalid)
● Navbar responsiva con menú colapsable
● Al menos 3 artículos de ejemplo
● Favicon
● Sin errores de accesibilidad (ARIA labels, contraste)
